# Scarlett's on Main Website Plan

Build a polished, warm, vintage-inspired website for **Scarlett's on Main**, a curated resale and vintage boutique located in Manchester, Connecticut.

Reference images are attached. Use them as the primary visual reference for the shop's branding, typography, colors, atmosphere, and overall aesthetic.

---

## 1. Brand Identity

### Business Name

Scarlett's on Main

### Tagline

"a sweet repeat shop"

### Business Description

Curated Resale and Vintage Boutique

### Overall Brand Feel

The website should feel:

- Warm
- Charming
- Vintage-inspired
- Curated rather than cluttered
- Personal and welcoming
- Feminine without feeling overly delicate
- Nostalgic but still modern
- Like a thoughtfully designed local boutique rather than a large retail store

The attached images should guide the visual direction.

Avoid:
- Generic e-commerce styling
- Overly modern/minimal corporate design
- Excessive animations
- Heavy gradients
- Dark or overly saturated colors
- Anything that makes the site feel like a generic template

---

## 2. Color Palette

Use these as the primary brand colors:

- **Blue:** `#A3C3CC`
- **Peach:** `#E8D5C1`

Use these colors throughout the site for backgrounds, accents, buttons, borders, cards, and other UI elements.

Keep the overall palette soft and cohesive. Additional neutral colors such as warm white, cream, beige, or charcoal may be introduced where necessary.

---

## 3. Typography

### Primary Display Font

Use **Bodoni Moda** for:

> Scarlett's on Main

Google Fonts import:

```css
@import url('https://fonts.googleapis.com/css2?family=Bodoni+Moda:ital,opsz,wght@0,6..96,400..900;1,6..96,400..900&display=swap');
```

The business name should have a large, elegant, high-contrast serif appearance similar to the attached storefront/sign reference.

### Script Font

Use SignPainter HouseScript for:

> a sweet repeat shop

This should be used sparingly as a decorative brand font, primarily for the tagline and potentially a few small accent elements.

If SignPainter HouseScript is not freely available as a web font, structure the CSS so the font can be added as a local/custom font later rather than substituting a generic cursive font everywhere.

### Supporting Font

Choose a complementary, highly readable font for:

- Navigation
- Body text
- Buttons
- Hours
- Contact information
- Section headings
- General UI

The supporting font should complement Bodoni Moda and SignPainter HouseScript without competing with them.

Prioritize readability and a classic/vintage feel.

## 13. Responsive Design

The website must work well on:

- Desktop
- Tablet
- Mobile

On mobile:

- Maintain the visual hierarchy of the storefront branding
- Make the business name readable without overwhelming the screen
- Ensure the script font remains legible
- Make navigation easy to use
- Make the address, email, and CTAs easy to tap
- Stack hours and content appropriately

---

## 14. Design Direction

Use the attached reference images heavily when making visual decisions.

The website should feel like the digital version of Scarlett's on Main's physical storefront.

Important visual characteristics to capture:

- Elegant serif typography
- Handwritten/sign-painter accent typography
- Soft blue and peach palette
- Vintage furniture / resale boutique atmosphere
- Warm neutrals
- Carefully curated visual composition
- Personal local-business character
- A balance between vintage and contemporary web design

Do not simply reproduce the storefront sign as a website. Translate its visual language into a complete, modern, responsive website.

---

## 15. Implementation Requirements

Before writing code:

- Review all attached reference images.
- Identify recurring visual patterns, typography, colors, spacing, and imagery.
- Create a cohesive design system based on those references.
- Keep the implementation clean and maintainable.
- Make reusable components for repeated UI elements.
- Keep content separate from presentation where practical so posts/hours can be updated easily.

### Ensure accessibility:

- Semantic HTML
- Proper heading hierarchy
- Keyboard navigation
- Visible focus states
- Sufficient color contrast
- Alt text for meaningful images
- Appropriate button/link labels

### Other requirements:

- Optimize images and avoid unnecessarily large assets.
- Make the site responsive from the beginning rather than adding mobile styling afterward.

The final result should feel like a real boutique website designed specifically for Scarlett's on Main, not a generic template with the business name and colors swapped in.
